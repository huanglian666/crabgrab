# CrabGrab 第二阶段：TMDB 图片下载设计

## 阶段目标

为 CrabGrab 增加第一项业务能力：用户提供带来源和媒体类型的 TMDB 资源 ID 以及一个父目录，程序从 TMDB 下载一张 `original` 横屏 backdrop 和一张 `original` 竖屏 poster，并分别保存到固定子目录。

本阶段同时建立可扩展的图片提供方策略边界。当前只实现 TMDB，后续可以在不改变 CLI 下载流程的前提下增加 IMDb、豆瓣等提供方。

## CLI 设计

### 下载图片

短参数形式：

```bash
crabgrab -i tmdb-movie-550 -o <父目录>
crabgrab -i tmdb-tv-1399 -o <父目录>
```

完整参数形式：

```bash
crabgrab --id tmdb-movie-550 --output <父目录>
crabgrab --id tmdb-tv-1399 --output <父目录>
```

行为约束：

- `-i` 是 `--id` 的短参数。
- `-o` 是 `--output` 的短参数。
- `--id` 与 `--output` 必须同时提供。
- 每次只接受一个资源 ID，不支持批量下载。
- `movie` 表示电影。
- `tv` 表示 TMDB 的电视节目，覆盖电视剧和综艺。
- 继续保留现有的 `-v`、`--version`、`-h` 和 `--help` 行为。
- 未提供下载参数或子命令时继续显示帮助并以非零状态退出。

### 初始化配置

```bash
crabgrab config init
```

该命令创建配置模板，不写入真实 Token，也不得覆盖已有配置文件。

## 资源 ID 设计

统一资源 ID 由提供方、媒体类型和提供方内部数字 ID 组成：

```text
<provider>-<media-type>-<numeric-id>
```

本阶段接受：

```text
tmdb-movie-550
tmdb-tv-1399
```

解析后形成与具体 CLI 表达无关的结构化资源 ID。以下输入必须在网络请求前拒绝：

- 未知提供方。
- 未知媒体类型。
- 缺少任一组成部分。
- 数字 ID 为空、不是整数或为零。
- 包含多余组成部分的输入。

## 提供方策略

定义统一的 `ArtworkProvider` 策略接口。策略接收结构化资源 ID，返回横屏背景图和竖屏封面的下载信息。

本阶段的策略注册表只注册 `TmdbProvider`：

- `tmdb-movie-<id>` 请求 TMDB movie 详情接口。
- `tmdb-tv-<id>` 请求 TMDB TV 详情接口。
- `TmdbProvider` 负责认证、TMDB 请求、响应解析以及将 TMDB 图片路径转换为 `original` 图片下载地址。
- 公共下载流程不依赖 TMDB 的响应结构或端点细节。

未来增加其他数据源时，应新增策略实现和注册项，不修改通用资源 ID 解析、下载事务或 CLI 主流程。

本阶段不实现动态插件系统、运行时加载第三方代码或提供方自动发现。

## 配置文件

### 配置格式

配置文件使用 TOML：

```toml
[tmdb]
api_token = ""
language = "zh-CN"
```

- `api_token` 保存用户自己的 TMDB API Read Access Token。
- `api_token` 缺失或去除首尾空白后为空时，下载命令必须在发送请求前失败。
- `language` 控制 TMDB 元数据和默认 poster 的语言选择。
- `language` 缺失时默认使用 `zh-CN`。
- Token 不得出现在命令参数、日志、错误信息或测试输出中。

### 双路径查找

下载命令按以下优先级查找配置：

1. 当前 CrabGrab 可执行文件同级的 `config.toml`。
2. 操作系统标准用户配置目录中的 `crabgrab/config.toml`。

如果同级配置存在，则不与系统配置合并，也不回退读取系统配置；同级配置无效时应直接报告该文件的问题，避免静默使用另一份 Token。

跨平台系统配置目录应通过可靠的目录解析库获取，不在源码中拼接固定用户目录：

- macOS 使用用户的 Application Support 配置位置。
- Linux 使用 XDG 配置位置。
- Windows 使用用户的应用配置位置。

### `config init` 行为

`crabgrab config init`：

1. 创建前先检查两个候选位置；任一位置已经存在配置时，报告现有配置路径并拒绝创建第二份配置。
2. 两个位置都不存在时，优先尝试在可执行文件同级创建 `config.toml`。
3. 如果同级目录不可写，则回退到系统配置目录的 `crabgrab/config.toml`。
4. 创建系统配置前先创建所需父目录。
5. 配置文件必须使用“仅当文件不存在时创建”的方式打开，避免并发初始化覆盖文件。
6. 成功后打印实际创建文件的绝对路径，并提示用户填写 Token。
7. 两个位置都无法创建时，以非零状态退出并报告候选路径和文件系统错误。

对“不可写”的判断必须以实际的安全创建操作结果为准，不预先依赖容易产生竞态的权限探测。

## TMDB 请求与图片选择

- 使用 TMDB API Read Access Token，通过 `Authorization: Bearer <token>` 请求头认证。
- movie 和 TV 使用各自的详情接口，不通过探测多个媒体接口猜测类型。
- 请求使用配置中的 `language`。
- 使用详情响应中的 `backdrop_path` 和 `poster_path` 作为本阶段的默认图片。
- backdrop 或 poster 任一个缺失时，整个下载操作失败，不生成部分结果。
- 使用 TMDB 图片配置提供的安全基础地址和 `original` 尺寸构造下载地址。
- 图片内容采用流式写入，不要求一次性载入内存。
- HTTP 客户端必须设置连接和整体请求超时，避免无限等待。
- 允许客户端遵循合理数量的 HTTP 重定向，不允许无限重定向。

TMDB 的语言规则由服务端决定：poster 优先使用请求语言，并按 TMDB 规则回退；backdrop 通常选择无语言的高评分图片。本阶段不调用图片列表接口自行排序，也不提供图片选择交互。

## 输出目录与文件名

用户传入的 `--output` 是父目录。最终目录固定为：

```text
<父目录>/
├── background/
│   └── background.jpg
└── cover/
    └── cover.jpg
```

- 横屏 backdrop 保存为 `background/background.jpg`。
- 竖屏 poster 保存为 `cover/cover.jpg`。
- 需要时自动创建父目录和两个子目录。
- 本阶段固定使用上述文件名，不在文件名中加入 TMDB ID、标题或语言。
- 下载 TMDB 返回的 JPEG 图片字节，不进行裁剪、压缩、转码或尺寸调整。
- 成功后打印两个最终文件的绝对路径。

## 覆盖与事务式更新

目标文件存在时默认覆盖，但不得边下载边覆盖正式文件：

1. 在各目标文件所在目录创建本次操作专用的临时文件。
2. 将 backdrop 和 poster 完整下载到临时文件，并确保写入完成。
3. 两张图片均成功后，才开始替换正式文件。
4. 替换前将已有正式文件移动为本次操作专用的临时备份。
5. 将两个下载临时文件重命名为正式文件。
6. 两个替换均成功后删除备份。
7. 任一替换失败时，尽最大可能恢复两个旧文件并删除本次临时文件。

普通文件系统不能为两个独立文件提供单一的跨文件原子提交。本阶段通过“完整暂存、备份、重命名、失败回滚”实现事务式更新，保证网络下载失败不会触碰旧文件，并降低文件替换失败造成混合版本的风险。

临时文件与备份名称必须避免与其他 CrabGrab 进程冲突。成功或失败退出时，都应尽量清理本次操作创建的临时文件和备份；不得删除无法确认属于本次操作的文件。

## 错误处理

所有失败都应以非零状态退出，并给出可操作且不泄露凭证的错误信息：

- 配置不存在：显示查找过的路径并提示运行 `crabgrab config init`。
- Token 缺失或为空：显示配置文件路径并提示填写 `[tmdb].api_token`。
- ID 无效：显示接受的格式示例。
- TMDB 返回 401：提示检查 Read Access Token。
- TMDB 返回 404：提示资源类型与 ID 不存在。
- TMDB 返回 429：提示触发服务限流，用户稍后重试。
- TMDB 返回其他 4xx 或 5xx：报告状态分类，不输出认证头或完整敏感响应。
- backdrop 或 poster 缺失：明确指出缺少的图片类型。
- 目录创建、文件写入、重命名或回滚失败：报告相关路径和操作。
- 网络连接、超时、重定向或响应读取失败：说明失败阶段。

成功输出写入标准输出；错误和诊断信息写入标准错误。

## 建议代码边界

建议按职责拆分：

```text
src/
├── main.rs
├── lib.rs
├── cli.rs
├── config.rs
├── domain.rs
├── domain/
│   └── resource_id.rs
├── providers.rs
├── providers/
│   └── tmdb.rs
├── artwork.rs
└── artwork/
    └── download.rs
```

- `main.rs`：启动程序并将最终结果转换为退出状态。
- `cli.rs`：定义 clap 参数、子命令和命令分派。
- `config.rs`：配置路径解析、读取、验证和初始化。
- `domain.rs` 与 `domain/resource_id.rs`：统一资源 ID 解析与验证。
- `providers.rs`：图片提供方接口、通用返回类型和策略注册。
- `providers/tmdb.rs`：TMDB 策略、认证、API 请求和响应解析。
- `artwork.rs` 与 `artwork/download.rs`：目录创建、流式下载、临时文件、替换与回滚。

实现时可以根据实际代码量适度合并小模块，但不得把 CLI、配置、TMDB 协议和文件事务全部堆入 `main.rs`。

为了让核心行为可测试，路径解析、HTTP 客户端或端点、文件替换操作应通过清晰接口注入测试替代，不得要求自动化测试访问真实 TMDB。

## 测试策略

所有新行为采用测试驱动开发。测试使用临时目录和本地模拟 HTTP 服务，不使用真实 TMDB Token，不访问公网。

### 资源 ID

- 接受 `tmdb-movie-550` 和 `tmdb-tv-1399`。
- 拒绝未知提供方、未知媒体类型、缺失部分、多余部分、非数字和零值 ID。
- 验证解析后的提供方、媒体类型和数字 ID。

### 配置

- 可执行文件同级配置优先于系统配置。
- 同级配置不存在时读取系统配置。
- 同级配置存在但无效时不静默回退。
- 缺失语言时使用 `zh-CN`。
- Token 缺失、空白或配置 TOML 无效时失败。
- `config init` 创建正确模板和父目录。
- 已存在的配置不被覆盖。
- 同级位置创建失败时回退系统配置位置。
- 错误输出不包含测试 Token。

### TMDB 策略

- movie ID 请求 movie 详情接口，TV ID 请求 TV 详情接口。
- 请求带有正确的 Bearer 认证和语言参数。
- 正确解析 backdrop 与 poster 路径。
- 使用 TMDB 图片配置与 `original` 尺寸构造地址。
- 覆盖 401、404、429、5xx、无效 JSON、路径缺失、连接失败和超时。
- 测试输出与错误信息不得泄露认证 Token。

### 下载事务

- 自动创建 `background` 和 `cover` 子目录。
- 两张图片保存到固定文件名。
- 两张图片均成功后替换正式文件。
- 任一下载失败时旧文件保持不变。
- 替换失败时尝试回滚旧文件。
- 成功和失败路径均清理本次临时文件与备份。
- 已存在文件默认被完整新文件替换。

### CLI 集成

- `-i/-o` 与 `--id/--output` 行为一致。
- ID 或输出目录缺失时非零退出并显示帮助或明确错误。
- 非法 ID 在网络请求前失败。
- `config init` 成功创建模板并报告路径。
- 重复初始化不覆盖配置并非零退出。
- 下载成功时输出两个最终绝对路径。
- 原有 `-v`、`--version`、无参数帮助和 `--help` 测试继续通过。

## 明确不做

本阶段不实现：

- IMDb、豆瓣或其他图片提供方，仅保留策略扩展点。
- 批量 ID、并发下载、后台任务或重试队列。
- 影片简介、演员、演职人员、评分、预告片或其他元数据保存。
- 剧集分季、分集图片或人物图片。
- 图片浏览、交互选择、自定义尺寸、裁剪、压缩、转码或格式转换。
- MediaInfo、FFmpeg、视频截图或字幕功能。
- 下载缓存、持久化任务状态或日志系统。
- 动态插件加载。
- README、CI、发布或安装流程。

除实现本设计所必需的改动外，不进行无关重构。

## 完成标准

- `crabgrab -i tmdb-movie-<id> -o <父目录>` 可以下载电影 backdrop 与 poster。
- `crabgrab -i tmdb-tv-<id> -o <父目录>` 可以下载电视剧或综艺 backdrop 与 poster。
- 两张图片均使用 TMDB `original` 尺寸并保存到固定目录和文件名。
- 双路径配置查找与 `crabgrab config init` 行为符合设计。
- TMDB Token 不出现在源码、命令参数、测试数据输出或错误信息中。
- 策略接口当前只实现 TMDB，但可以在不修改公共下载流程的情况下增加其他提供方。
- 下载失败不破坏已有正式图片，替换失败执行回滚与清理。
- 自动化测试覆盖 ID、配置、TMDB 响应、下载事务和 CLI 用户可见行为。
- 原有版本与帮助行为没有回归。
- 格式、编译、测试及差异检查全部通过。
- 没有实现本阶段范围之外的业务功能。
