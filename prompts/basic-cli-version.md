# CrabGrab 最小 CLI 版本命令实施提示词

请在 CrabGrab Rust 项目中实现第一阶段的最小命令行程序。本阶段只建立 CLI 基线和版本查询能力，不实现影片资料、MediaInfo 或视频截图功能。

## 目标

让用户可以执行以下命令查看程序版本：

```bash
crabgrab -v
```

预期输出：

```text
crabgrab 0.1.0
```

版本号必须来自 `Cargo.toml` 中的 `package.version`，不得在 Rust 源码中重复硬编码。

## 技术方案

- 使用 `clap` 的派生宏 API 构建 CLI。
- 使用 `env!("CARGO_PKG_VERSION")` 或 `clap` 支持的等效编译期机制读取包版本。
- `-v` 和 `--version` 都应输出相同的版本信息。
- `clap` 默认可能使用大写 `-V` 作为短版本参数，必须显式配置为本项目要求的小写 `-v`，不得只实现 `-V`。
- 未提供任何参数时显示帮助信息，而不是静默退出或执行其他行为。
- CLI 名称固定为 `crabgrab`。

## 实现范围

允许修改：

- `Cargo.toml`
- `Cargo.lock`
- `src/main.rs`
- 为 CLI 行为新增的测试文件

需要完成：

1. 添加满足当前功能所需的 `clap` 依赖及派生宏特性。
2. 定义最小 CLI 参数结构。
3. 实现 `-v` 和 `--version`。
4. 配置无参数时显示帮助信息。
5. 添加自动化测试，验证命令退出状态以及标准输出或标准错误中的用户可见内容。

## 明确不做

本阶段不得实现或提前搭建以下内容：

- 影片资料、海报、封面或演职人员获取。
- MediaInfo 或 FFmpeg 调用。
- 视频截图或字幕选择。
- 业务子命令。
- 配置文件。
- 日志系统。
- 网络请求。
- README、CI 或发布流程。

除实现本提示词要求所必需的改动外，不进行无关重构。

## 行为要求

### 短版本参数

执行：

```bash
cargo run -- -v
```

应成功退出，并输出：

```text
crabgrab 0.1.0
```

### 长版本参数

执行：

```bash
cargo run -- --version
```

应成功退出，并输出：

```text
crabgrab 0.1.0
```

### 无参数

执行：

```bash
cargo run --
```

应显示帮助信息并以非零状态退出，表示缺少必要的命令或参数。帮助信息可能由 `clap` 写入标准错误流，测试应合并检查标准输出和标准错误，而不是限定输出流。帮助信息至少应包含：

- 程序名 `crabgrab`
- `Usage` 或等效用法说明
- `-v`
- `--version`
- `-h`
- `--help`

无参数行为不得触发业务逻辑。

## 测试要求

优先编写集成测试，通过启动编译后的 `crabgrab` 二进制文件验证用户可见行为。对帮助信息应同时检查标准输出和标准错误。测试至少覆盖：

1. `-v` 成功退出且输出包含准确的程序名和当前包版本。
2. `--version` 成功退出且输出与 `-v` 一致。
3. 无参数时以非零状态退出并显示帮助信息。
4. `--help` 成功退出并显示帮助信息。

测试不得把 `0.1.0` 作为独立于包配置的长期固定值重复维护；应尽可能根据 Cargo 包版本构造预期结果。

## 验证步骤

实现完成后依次执行：

```bash
cargo fmt --check
cargo check
cargo test
cargo run -- -v
cargo run -- --version
cargo run --
git diff --check
git status --short
```

检查以下事项：

- 格式、编译和测试命令成功；无参数运行按约定以非零状态显示帮助。
- `-v` 与 `--version` 输出一致。
- 输出版本与 `Cargo.toml` 中的版本一致。
- 无参数时显示帮助信息。
- `Cargo.lock` 保持跟踪并包含依赖变化。
- 没有构建产物、临时文件或无关文件进入待提交范围。

## 完成标准

- `crabgrab -v` 输出 `crabgrab <当前包版本>`。
- `crabgrab --version` 与 `-v` 行为一致。
- 无参数时显示帮助信息。
- 自动化测试覆盖核心 CLI 行为。
- 格式、编译和测试验证全部通过。
- 没有实现本阶段范围外的业务功能。
